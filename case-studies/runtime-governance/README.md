# Case Study Surface — Runtime Governance

## Why This Surface Exists

Many contemporary governance claims are performative:

- policy exists as prose
- evidence exists as logs
- oversight exists as ceremony

But the real question is whether governance executes at runtime.

This case-study surface exists to collect bounded examples where the declared
governance layer and the actual runtime behavior diverge.

## Likely In-Scope Anti-Patterns

- `AP007` Policy PDF, Runtime Nothing
- `AP008` Evidence After Action
- `AP009` Human Oversight as Ceremony

## Working Questions

- where is policy actually bound to runtime execution?
- which controls are preventive, and which are only retrospective?
- can the human oversight path stop the meaningful failure mode in time?
- what evidence is replayable rather than merely descriptive?

## Editorial Rule

This surface should stay concrete.

A good runtime-governance case study should show:

- the declared governance claim
- the runtime reality
- the anti-pattern linkage
- the tightening path
