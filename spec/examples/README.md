# Spec Examples

Worked examples for the governance fragility profile schema.

These are illustrative, not normative. Their purpose is to show:

- how to populate lifecycle and risk-profile fields
- how anti-patterns link back to deeper failure classes
- how evidence levels should be stated honestly

## Current examples

- `example-profile-agent-commerce-pattern.json`
  Example GF profile for delegated-accountability problems in agentic commerce.
- `example-profile-runtime-governance.json`
  Example GF profile for weak runtime governance after launch.
- `example-aiid-governance-crosswalk.json`
  JSON record shape for mapping an incident record into governance failure
  classes and mitigations.
- `example-aiid-governance-crosswalk-runtime-drift.md`
  Markdown worked example for a lifecycle-break / runtime-drift reading.
- `example-aiid-governance-crosswalk-accountability.md`
  Markdown worked example for an accountability-displacement reading.
