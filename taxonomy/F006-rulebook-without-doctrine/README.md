# F006 — Rulebook Without Doctrine

## Claim

An institution can accumulate many policies, regulations, guidance documents,
and repair packages while still lacking a stable doctrine that couples them
into one coherent operating logic over time.

## Mechanism

The failure emerges when:

- policy instruments are created locally
- trade-offs are handled instrument by instrument
- no enduring objective or principal contradiction is kept stable across the
  stack
- later coherence is attempted through simplification or repair packages

## Observable Signature

- many rules with weak strategic coupling
- shifting trade-off logic across instruments
- omnibus or simplification packages doing coherence work after the fact
- implementation guidance functioning as de facto strategy

## False Reassurance Pattern

The institution looks serious because the rule stack is large and active. In
practice, the stack drifts because no doctrine ranks priorities and couples the
instruments.

## Minimal Assumptions

- a multi-instrument policy stack exists
- instruments can conflict or create implementation friction
- no stable doctrine governs trade-offs across the stack

## Where It Does Not Apply

This class is weaker where a clear doctrine exists, is stable across
instruments, and is used to justify new additions before the stack grows.

## Typical Cases

- digital or AI policy stacks built through successive local measures
- institutional governance programmes that rely on later simplification to
  restore coherence

## Mitigations

- define the enduring objective and principal contradiction explicitly
- define trade-off ranking across the policy stack
- require doctrinal fit for new instruments

## Residual Risk

Even with a doctrine, democratic contest and implementation friction still
remain. Doctrine reduces uncoupling; it does not remove politics.
