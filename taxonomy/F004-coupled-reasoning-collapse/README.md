# F004 — Coupled Reasoning Collapse

## Claim

An iterative reasoning process can remain apparently stable until a small
perturbation causes abrupt reorganization of the recommendation regime.

## Mechanism

Later outputs recursively depend on earlier framings in a coupled loop. Without
strong external correction, the system can cross a framing boundary and shift
qualitatively rather than gradually.

## Observable Signature

- abrupt recommendation shifts after small framing changes
- polished convergence preceding reorganization
- disagreement disappearing before the underlying issue is resolved

## False Reassurance Pattern

The process looks healthier as it collapses because surviving perspectives
expand and the resulting output becomes more coherent and readable.

## Minimal Assumptions

- iterative coupled reasoning
- weak external error signal
- participants or agents are not independent
- polished consensus is rewarded

## Where It Does Not Apply

This class does not automatically apply to deterministic or replayable
measurement systems whose state is not recursively reshaped by interaction.

## Mitigations

- constitutional layer above the reasoning loop
- provenance separation
- bounded AI role
- explicit draft versus authority distinction
