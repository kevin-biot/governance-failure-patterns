# Docs

This directory contains longer-form method notes, crosswalks, and guidance that
sit between the top-level taxonomy and the formal `spec/` layer.

## Current documents

- [aiid-governance-crosswalk-method.md](./aiid-governance-crosswalk-method.md)
  Defines how to map public AI incident records into governance failure
  classes, anti-patterns, constructive patterns, and candidate mitigations.
- [aiid-governance-crosswalk-playbook.md](./aiid-governance-crosswalk-playbook.md)
  A practical operating guide for doing crosswalk work consistently.
- [aiid-governance-crosswalk-mapping-matrix.md](./aiid-governance-crosswalk-mapping-matrix.md)
  A starter matrix from common incident signals to likely governance
  interpretations and mitigation shapes.
- [aiid-taxonomy-inventory-and-mapping-backlog.md](./aiid-taxonomy-inventory-and-mapping-backlog.md)
  An inventory of AIID taxonomy surfaces and an explicit backlog for future
  governance crosswalk work.

## Why this layer exists

Some work is too detailed for the root README but too explanatory to live only
as schema or test files.

This directory holds that middle layer:

- method
- interpretation rules
- worked mapping logic
- reusable explanatory notes
