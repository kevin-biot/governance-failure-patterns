# Pattern — Counter-Frame Record

## Purpose

A counter-frame record keeps one analytic framing from becoming invisible
doctrine.

## Core moves

- state at least one serious alternative framing
- record how conclusions change under that framing
- preserve disagreements rather than smoothing them away
- make frame dependence part of the published result

## What this prevents

- one model frame silently becoming constitutional
- consensus generated by frame narrowing rather than validation
- weaker forms of `AP003` AI Consensus as Validation

## Minimal artefacts

- primary frame
- counter-frame
- changed assumptions
- changed result or unchanged result with explanation

## Working question

If we framed the problem differently, would the recommendation still survive?

## Boundaries

The goal is not infinite reframing. The goal is to show whether the conclusion
depends heavily on one unchallenged frame.
