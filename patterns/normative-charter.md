# Pattern — Normative Charter

## Purpose

A normative charter makes the value commitments of a framework explicit before
measurement, scoring, or optimization begins.

## Core moves

- state the governing values up front
- define which trade-offs are acceptable and which are not
- name protected stakeholders or protected futures explicitly
- separate normative commitments from later analytic machinery

## What this prevents

- values being inferred from indicators after the fact
- hidden normativity inside apparently technical scoring systems
- weaker forms of `AP004` Constitution After the Model

## Minimal artefacts

- a short value statement
- trade-off hierarchy
- protected interests list
- rule for how normative changes are versioned

## Working question

What values govern the system before the model starts speaking?

## Boundaries

A charter does not eliminate disagreement. It makes the governing commitments
visible enough to be contested honestly.
