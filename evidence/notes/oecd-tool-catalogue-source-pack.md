# OECD Tool Catalogue Source Pack

Checked on: 2026-04-23

## Purpose

This note records the public source basis for the repository's OECD Catalogue
crosswalk work.

It exists to keep the boundary explicit between:

- what OECD publishes directly
- what this repository infers about mitigation fit and governance gaps

## Public Sources Used

### 1. OECD Catalogue overview

URL:
https://oecd.ai/en/catalogue/overview

Why it matters:

- confirms the catalogue exists as a public tool and metric inventory
- confirms its stated purpose as a one-stop-shop for approaches, mechanisms,
  and practices for trustworthy AI
- confirms the catalogue disclaimer that listed tools are not endorsed by OECD

### 2. OECD Catalogue FAQ / About page

URL:
https://oecd.ai/en/catalogue/faq

Why it matters:

- explains that the catalogue includes technical, procedural, and educational
  tools
- explains the submission and review model
- explains that some taxonomy fields are annotated using ChatGPT and then
  reviewed for data quality
- confirms the catalogue is not equivalent to certification

## What is source-backed

The following are treated as source-backed:

- OECD maintains a public catalogue of tools and metrics for trustworthy AI
- the catalogue includes technical, procedural, and educational tools
- the catalogue supports public submissions and use cases
- the catalogue is not an endorsement or certification list

## What is analytic inference

The following are this repository's interpretation:

- that the OECD catalogue can serve as a mitigation-side crosswalk source
- that some governance failure patterns have stronger public tool support than
  others
- that some governance surfaces remain structurally thin because they are
  institutional-design problems rather than tool problems

## Editorial rule

This repository should not imply:

- that OECD endorses any specific tool's effectiveness
- that a listed tool closes a governance gap by default

The correct use is:

- public mitigation-supply source
- bounded governance interpretation layer

## Maintenance rule

If OECD changes the catalogue structure or methodology:

- update the OECD crosswalk method
- update the gap analysis note
- preserve the distinction between source-backed catalogue facts and this
  repository's governance interpretation
