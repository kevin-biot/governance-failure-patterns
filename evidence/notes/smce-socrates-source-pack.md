# SMCE/SOCRATES Source Pack

Checked on: 2026-04-23

## Purpose

This note records the source pack used for the `SMCE/SOCRATES` case study and
separates:

- public sources used for source-backed claims
- private drafting substrates used only during incubation

## Public Sources Used

### 1. Official SOCRATES overview page

URL:
https://knowledge4policy.ec.europa.eu/projects-activities/socrates-social-multi-criteria-assessment-european-policies_en

Why it matters:

- confirms the current public positioning of SOCRATES
- describes the three core components
- states the Kemeny non-compensatory rule
- states that SOCRATES is not meant to substitute policymakers

Checked claims:

- page last updated 27 Feb 2026
- multi-criteria / equity / sensitivity structure
- mixed qualitative and quantitative inputs
- Kemeny aggregation
- explicit non-substitution language

### 2. SOCRATES manual

URL:
https://publications.jrc.ec.europa.eu/repository/bitstream/JRC131755/JRC131755_01.pdf

Why it matters:

- deeper technical support for the public SOCRATES description

Use in current case:

- supporting source only; primary case-study claims rely mainly on the public
  overview page unless a manual-level detail is required later

### 3. JRC intergenerational fairness page

URL:
https://joint-research-centre.ec.europa.eu/jrc-science-intergenerational-fairness_en

Why it matters:

- confirms the public positioning of the intergenerational-fairness tool stack
- confirms the public status of Futures Balance and the planned monitoring tool

Checked claims:

- Futures Balance listed as AI-assisted and in prototyping phase
- Intergenerational Fairness Monitoring Tool listed as coming April 2026

### 4. Futures Balance policy brief

URL:
https://publications.jrc.ec.europa.eu/repository/bitstream/JRC145994/JRC145994_01.pdf

Why it matters:

- gives the clearest public description of how AI is being inserted into the
  workflow

Checked claims:

- interoperable with SOCRATES rather than replacing it
- prototype status
- iterative reliability improvements underway
- AI assistance for framing, goals, criteria, and initial option development
- human-in-the-loop limits and exploratory-use framing

### 5. SIWB dashboard report

URL:
https://publications.jrc.ec.europa.eu/repository/bitstream/JRC140456/JRC140456_01.pdf

Why it matters:

- gives the public monitoring methodology relevant to the drift critique

Checked claims:

- dashboards use relative values in a pooled 2011-2022 reference distribution
- missing values are imputed for all indicators and all years
- component and overall synthetic indices are medians of percentile positions
- five-colour dashboard communication layer

## Rule for Future Expansion

If this case study is expanded, every added claim should be tagged mentally as
one of:

- source-backed from public JRC/EC material
- inference from public material
- private incubation inference not yet suitable for public release

That distinction should remain visible in the case-study prose.
